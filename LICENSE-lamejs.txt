lame.min.js — LAME MP3 encoder, JavaScript port
================================================

Handpan Studio uses this library for MP3 audio export, and for nothing else.

lame.min.js is vendored BYTE-FOR-BYTE UNMODIFIED, kept as its own file, and
loaded at runtime only when someone actually exports an MP3. Nothing in
app.html is linked into it and nothing in it has been changed. That is
deliberate: it is the arrangement lamejs's own licence file asks for, quoted
here in full.

    Can I use LAME in my commercial program?

    Yes, you can, under the restrictions of the LGPL.  The easiest
    way to do this is to:

    1. Link to LAME as separate jar (lame.min.js or lame.all.js)

    2. Fully acknowledge that you are using LAME, and give a link
       to our web site, lame.sourceforge.net

    3. If you make modifications to LAME, you *must* release these
       these modifications back to the LAME project, under the LGPL.

Points 1 and 3 are met by the paragraph above. Point 2 is met here and in the
app itself: the export dialog credits LAME and links to lame.sourceforge.net.

IF THIS FILE IS EVER UPDATED, re-check the hash above and keep it unmodified.
The moment it is edited rather than replaced, point 3 turns those edits into
something that must go back to the LAME project — which is a promise nobody
wants to make by accident while fixing a bug at midnight.
