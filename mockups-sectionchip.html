2 · What it is being matched to

The arrangement navigator, in the drawer. This is the black he is asking about — and worth noticing: down there the black means “the one playing”, with the others sitting pale beside it. A lone chip in the header has nothing to be darker than, so it borrows the emphasis without the contrast that gave it meaning.

4 · The trade, in one table

ReadingConsistent with the navigatorWeight on the pageFindable
A as it shipsNo — different shape, different colourNonePoor
B black pillExactlyHeaviest thing above the scoreImmediately
C pill, not fillSame shape and metrics, lighter colourLevel with the room pillGood
D amber pillSame shape, app's own “you are here”Light but colouredGood
What I would do — C. His instinct about the black is right, and it has a reason behind it: in the navigator the black means the one playing, and it only reads that way because the chips beside it are pale. A single chip in the header has nothing to contrast with, so it takes the emphasis and drops the meaning — the darkest object on screen would be a section label sitting above the music it labels. C gives him what he actually asked for, which is that a section chip is the same kind of object everywhere: same pill, same radius, same 13/600, same padding. Only the fill differs, and the fill is the part that carries state rather than identity.

D is the one to look at if C reads as too quiet on his own screen — amber already means this is where you are throughout the app, so it is honest here. It costs one more amber object on a page that already has the playing marker.
