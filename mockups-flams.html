Flams in the notation

A flam is two strokes so close that they read as one accent: a quiet grace a hair before the main note. In this notation it should look like a chord, because rhythmically it is one — same slot, same count — with the grace set off from the stack so the eye knows which stroke leads.

The one sentence under every drawing below: a flam is a stack in which one event is marked as the grace — flam:true on that event, same t as the rest — and the player fires the grace 30 ms early at 55 %. That is the roll's own mechanism (roll:true, −45 ms, 45 %), already in the app, applied to a second note instead of the same one. No new grid, no 32nds, nothing changes in the stored bars except one flag.

Each option is shown on all three score sheets with four cases: a two-hand flam (green 5 into black 3), a same-note flam (D into D — the classic), a flam into a two-note chord, and the first case under the playback marker with the grace's own stroke flash. Below each: a tight row at the phone's true size, one bar of sixteenths, which is where every drawing is really judged.

Writing one in the editor

The stack already exists: tapping a second field on the same slot stacks it. A flam is that gesture plus one chip, which marks the note you place next as the grace.

  1. Tap the main note on the pan — it lands on the cursor's slot as today.
  2. Tap Flam. The chip lights, violet-dashed here only to mark it as new.
  3. Tap the grace note — it joins the slot's stack carrying flam:true, and the chip goes out again (one grace per flam, so the chip is a one-shot like Ghost is). The hand follows Alt as it always does, so a same-note D-into-D flam is two taps on the ding.
  4. Keyboard: F before the second number. The lane cell shows the nudge at once.

Roll has no chip today (the tilde exists only in transcribed pieces). If Flam gets one, Roll belongs beside it as a second one-shot — the two graces the notation knows — and that is a general change the same round would carry into the groove bench and the desktop's key row.
