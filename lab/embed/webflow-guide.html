Handpan Studio under the lesson videos

Paste guide for masterthehandpan.com (Webflow + Wized, Vimeo video) — 2 September 2026

Handpan Studio is David Kuckhermann's notation player. It sits in an iframe below a lesson video and follows the video: when the video plays, the notation moves with it, and the student can switch on pan sound, loop a section, or transpose the piece to their own handpan.

It comes in two pieces, and they go in two different places in Webflow. This is on purpose: a Webflow Embed element has a character limit, and the whole thing in one embed is over it. The first paste of the complete block silently lost its script, which is why the player showed no video bar.

Part 1 — the bridge script, once, site-wide

The bridge is the small script that reads the Vimeo player's clock and passes it to the app. It does nothing on pages without the app's iframe, so it is safe to have on every page.

  1. Open the file webflow-bridge.html in a text editor (TextEdit, VS Code, Notepad — anything). Select all, copy.
  2. In Webflow, open the project and go to Site settings (the gear icon, or Project settings) → Custom code tab.
  3. Scroll to Footer code (the box labelled "before </body> tag"). If it already holds code, click at the very end of it and press Enter to start a new line. Paste.
  4. Click Save changes.
Footer code only runs on the published site, never in the Designer or its preview. Nothing happens until you publish (step 3 of Part 2).

Part 2 — the lesson embed, on the lesson page

This is the iframe that holds the app, with the piece (Composition 2) and its video timing built into its address. It replaces what is in the Embed element now.

  1. Open the file webflow-embed-composition2-iframe.html in a text editor. Select all, copy.
  2. In the Webflow Designer, open the lesson page (the one that shows at /dashboard/lesson/…) and select the existing Embed element below the video — the one that currently holds the Handpan Studio iframe. If there is none yet, drag an Embed element (Add panel → Components → Embed) to just below the video player.
  3. Double-click the Embed element to open its code editor. Select all of the code in it and delete it, then paste. Click Save & Close.
  4. Publish the site.
Paste the file's contents exactly; do not reformat or "clean up" the long address in the iframe — that long string is the piece and its video timing.

Part 3 — check that it works

  1. Log in as a student and open the lesson. Let the video load.
  2. Below the notation, a small Video bar should appear and read ready. That means the bridge found the Vimeo player.
  3. Press play on the video. A Follow video button lights up in the app and the notation moves with the video. The space bar on the page also plays and stops.
If you see the Video bar with "ready", everything is connected.

If instead:

  • No Video bar at all → the footer script is not on the page. Check Part 1 was saved, and that the site has been published since.
  • "searching…" then "no player found" → the script runs but cannot reach the video player. Tell David; include which browser you used.
  • The notation runs early or late → the video timing was recorded against a different upload of the same video. Tell David; it takes a few minutes to re-record on your page.
  • A note saying "please open it from your lesson page" → the address in the Embed is not the one from the file; paste it again.

Good to know

  • One page, many lessons. If /dashboard/lesson/… is a single Wized template page that shows every lesson, this Embed will show Composition 2 under every lesson. That is fine for a first test. For one piece per lesson, the iframe's address needs to come from your lesson data (a field holding the Handpan Studio link) and be set by Wized — David can supply a link per lesson and the two of you can decide how to wire it.
  • Students never see the app's access key. It travels inside the iframe address, and the app drops it from view. The key in this file is specific to masterthehandpan.com.
  • Sound is off by default inside a lesson: the student hears the video, and can switch the pan samples on with the Sound button.
  • Changing Vimeo settings is not needed. The bridge works with the player as it is embedded now, and the video's domain privacy already allows your site.
